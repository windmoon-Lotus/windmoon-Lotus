贡献展示原则（避免“厚此薄彼”）

本项目的展示规则强调“可追溯、可理解、可持续”，并避免把贡献变成竞赛： 不设榜单、不做贡献量对比、不突出单一人物。 动态轮播仅按贡献时间展示“最新更新”，不代表贡献高低。

行业洞察（行业脉络/生态/趋势） 职业词条（岗位职责/路径/能力图谱） 访谈/一手报告（真实案例/实践复盘） 校对/审核（一致性/可读性/结构化） 工具/模板（问卷/模板/流程） 资源整理（课程/书单/链接）
公平性兜底：
1）轮播仅展示最新若干条，页面同时提供“全部贡献记录（时间线）”；
2）每条记录使用同一模板（同权信息密度），详细说明采用折叠展开；
3）不展示排名、贡献值、贡献数量等可能引发比较的数据。

参与共创

1）完善职业词条：通过 Pull Request 更新内容；
2）贡献新知：基于模板补充行业/岗位的一手信息；
3）参与共创：认领一个主题，完成访谈/整理/校对；
4）提问讨论：用 Issues 发起问题与反馈。

如何被“时间线”收录

贡献合入后，将一条事件写入首页的数据区（或未来自动化生成）。字段固定、模板固定，避免主观评价与比较： 时间、行业/职业、贡献类型、摘要、详细说明（可选）、证据链接。

隐私需要时，可仅展示 @handle 或匿名；“详细说明”建议遵循统一结构：做了什么 / 解决什么 / 影响面 / 链接证据。
