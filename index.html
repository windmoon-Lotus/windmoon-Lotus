贡献人荣誉展示原则（避免“厚此薄彼”）

本项目的“荣誉展示”遵循三条底线：不设榜单、不做贡献量对比、不突出单一人物。展示重点放在“贡献类型与影响面”，而非“数量与排名”。

行业洞察（行业脉络/生态/趋势） 职业词条（岗位职责/路径/能力图谱） 访谈与一手报告（真实案例/实践复盘） 校对与审核（一致性/可读性/结构化） 工具与模板（问卷/模板/流程） 资源整理（课程/书单/链接）
为了公平：
1）贡献人展示采用等尺寸卡片与同权信息密度；
2）默认排序使用拼音/字母序或随机轮换（可切换）；
3）“荣誉”以贡献类型徽章呈现，不使用“TOP/冠军/第X名”；
4）每个行业/职业的“共创荣誉”优先展示团队成果（新增/完善/校对/访谈等维度），弱化个人对比。

参与共创

贡献方式（任选其一）

1）完善职业词条：通过 Pull Request 更新内容；
2）贡献新知：基于模板补充行业/岗位的一手信息；
3）参与共创：认领一个主题，完成访谈/整理/校对；
4）提问讨论：用 Issues 发起问题与反馈。

发起 PR Pull Request 发起 Issue Discussion

如何被“公平致谢”

提交内容后，只需在对应行业/职业条目里补充一行贡献信息（或在 PR/Issue 中声明），即可被自动纳入“行业×职业荣誉墙”。
贡献类型采用统一枚举（徽章），避免主观评价与对比。

建议填写字段：姓名/昵称、GitHub、贡献类型、一句话贡献说明。
隐私需要时，可仅展示 @handle 或匿名。
