# windmoon-Lotus GBrain 归档规则

## 项目边界

本脑库只归档 `windmoon-Lotus` 发布项目相关内容：

- 发布站信息架构
- 人物档案
- 文章栏目和同步规则
- 「人生五年」当前主线
- 「百家职业共享」已结束项目归档

不导入 `F:\播客相关` 中定稿前的播客素材、原始转录、时间码和剪辑工作稿。

## 同步规则

- 发布站内容来自 `F:\笔记汇总\git\人生五年` 和 `F:\笔记汇总\git\百家职业共享大全`。
- `scripts/migrate-content.mjs` 负责把定稿 Markdown 同步进 `content/` 和 `data/articles.json`。
- 人物档案由 `data/people.json` 维护，不从播客工作区自动合并。

## 角色划分

- `人生五年`：当前主线，记录长期受访者。
- `百家职业共享`：已结束项目，作为归档样本和项目前史。
- `播客相关`：定稿前工作区，不直接进入发布站。
