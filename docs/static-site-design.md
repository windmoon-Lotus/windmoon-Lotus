# 「人生五年」个人介绍静态网站设计文档

## 1. 网站定位

本网站是「悠然 / windmoon-Lotus」的个人介绍与项目入口，但不以个人履历为第一主角，而是通过「人生五年」的受访者故事呈现其长期关注：

- 记录不同的人如何生活、如何选择、如何被时代、关系与时间塑造。
- 让读者先看见具体的人，再理解项目、随笔和共创网络。
- 将「百家职业共享 / 多元人生图鉴」作为前史、方法库与贡献者生态补充展示。

核心表达：**以受访者为主线，以随笔为思想脚注，以贡献者为信任来源。**

## 2. 目标读者

- 想了解「人生五年」是什么、为什么值得持续关注的人。
- 正在迷茫、希望通过真实人生样本获得参照的人。
- 可能成为受访者、贡献者、审校者或传播者的人。
- 想快速了解发起者关注领域与做事方式的人。

## 3. 内容主次

### 一级主线：受访者

首页最重要的内容是已完成的人生五年访谈：

1. **Yamu**：00后自由职业者、一人公司、连续创业者。主题为独立背后的重量、创业挣扎、社交与消费逻辑、五年后想要的生活。
2. **刘进步**：85后保险代理人，曾在基建投资领域工作十年。主题为职业转型、时代周期、情绪与控制感、关系与城市归属、35岁之后的自我选择。
3. **流年**：离职两年多、暂时没有重新进入职场的95后男性。主题为工作暂停、游戏与生活、舒适状态、找工作、亲密关系期待和五年后的自己。

展示方式：

- 每位受访者使用横向人物卡片。
- 卡片中突出「不是职业标签，而是人生切片」。
- 每张卡片包含人物介绍、关键词、五年后的追问、关联文章切换与可阅读入口。
- 同一受访者可关联多篇内容，例如访谈主稿、人物故事稿、职业共享旧稿；首页默认展示主稿，但允许读者在卡片内切换阅读入口。

### 二级补充：随笔与思想脉络

随笔不是文章列表堆砌，而是说明发起者如何从个人经验、阅读、社会观察中形成访谈问题意识。

建议分为三类：

- **成长与教育**：县中孩子、读书的料、学习误区。
- **时代与能力**：AI时代学习、情绪经济、适者所需的环境与基础能力。
- **生活实践**：海南骑行、农家研学、农村发展、消费与经济常识。

展示方式：

- 使用紧凑文章卡片。
- 每张卡片展示标题、简短说明、所属主题。
- 不抢受访者主线，只作为「为什么会这样提问」的背景。

### 三级补充：项目贡献人与职业共享前史

「百家职业共享 / 多元人生图鉴」承担三个作用：

- 解释「人生五年」并非突然出现，而是从职业信息共创逐渐转向更关注人的长期变化。
- 呈现项目的伦理底线：授权、脱敏、真实与克制。
- 致谢推动项目形成的人：受访者、建议者、模板审校者、共创者。

展示方式：

- 设置「从职业到人生」时间线。
- 设置贡献者致谢墙，优先展示角色与贡献，不制造排名感。
- 使用少量统计数字帮助读者感知项目规模。

## 4. 页面结构

### Hero

首屏不做营销式大标题，而是直接建立气质：

- 主标题：人生五年
- 副标题：记录不同的人如何生活、选择、坚持，以及如何被时间改变。
- 视觉：访谈笔记、录音笔、纸张、热茶的图像，强调真实访谈与长期记录。
- 行动入口：阅读受访者、留下你的五年、投稿或联系。

### 关于发起者

简短介绍悠然 / windmoon-Lotus：

- 网安从业者。
- 理想主义的项目发起者。
- 从职业信息共享出发，逐渐转向记录更完整的人。

该部分不宜过长，避免把网站变成个人简历页。

### 受访者主线

展示 Yamu、刘进步与流年三位已完成访谈受访者。后续样本不在首页以“下一批”静态占位呈现，避免已完成样本仍停留在待访状态。

### 随笔与问题意识

展示随笔分组，说明这些文章如何为访谈提供问题来源：

- 人生意义、婚姻观、人生几道坑。
- 县中教育、寒门成长、学习方法。
- AI、情绪经济、农村发展、创意与团队。

### 从「百家职业共享」到「人生五年」

用时间线展示转变：

- 2025年5月：最初尝试职业信息共创。
- 2025年12月：开启首次职业访谈。
- 2026年3月：项目开始意识到单纯职业信息不足以解释完整人生。
- 2026年4月：形成「人生五年」长期追踪访谈。

### 贡献者与信任

展示贡献者类别：

- 受访者：提供真实故事。
- 项目建议者：帮助修正方向与机制。
- 模板与审校贡献者：提升访谈质量。
- 传播与反馈者：帮助项目连接更多人。

### 参与方式

简洁说明：

- 成为受访者。
- 提供访谈线索。
- 参与整理、审校、模板优化。
- 关注五年后的回访。

## 5. 视觉设计

设计气质：安静、真实、可阅读、有人味。

- 色彩：米白纸张底色、深墨色文字、绿色作为行动色、酒红/赭色作为强调色。
- 字体：系统中文字体，保证本地打开稳定。
- 布局：宽屏双栏，移动端单栏。
- 组件：人物卡片、时间线、文章列表、贡献者短卡、标签。
- 图片：使用访谈笔记视觉图作为首屏和内容气质锚点。

避免：

- 过度营销式英雄区。
- 大量悬浮卡片嵌套。
- 单一紫蓝渐变或纯装饰背景。
- 用空泛口号替代具体人物。

## 6. 技术实现

本次实现为零依赖静态站，并将文章内容沉淀到发布库内部：

- `index.html`：页面结构与内容。
- `styles.css`：响应式视觉样式。
- `script.js`：轻量交互，包括人物切换、文章筛选、滚动激活导航。
- `assets/interview-notes.png`：首屏视觉图。
- `content/`：从「人生五年」和「百家职业共享」迁移过来的 Markdown 正文。
- `data/articles.json`：文章统一索引，记录标题、栏目、来源路径、摘要与正文路径。
- `articles/index.html`：总文章库。
- `articles/view.html`：文章详情页。
- `data/people.json`：人物档案索引，覆盖受访者、贡献人、双重角色与相关文章关联。
- `people/index.html`：人物档案页。
- `people/profile.html`：人物单独介绍页。
- `contributors/index.html`、`contributors/profile.html`：旧贡献者路径兼容跳转到人物系统。
- `life/`、`career/`、`essays/`、`topics/`、`templates/`、`encyclopedia/`、`projects/`、`tools/`：各栏目独立文章链接页。
- `scripts/migrate-content.mjs`：内容迁移脚本，用于从源资料库重新生成 `content/` 和 `data/articles.json`。
- `scripts/content-policy.mjs`：统一维护前台标题、精选文章与公开状态规则。

文章索引使用三级发布状态：

- `published`：进入主文章库和栏目页。
- `archive`：仅在「资料归档」或项目资料页展示。
- `draft`：保留在仓库与索引中，前台默认不展示。

同步源 Markdown 时，迁移脚本会自动补充 `displayTitle`、`status`、`featured`，并生成尽量在完整句子处结束的摘要。正式标题与 GitHub 源文件名彼此独立，原始路径仅在文章页的「查看素材来源」中展示。

页面部署在 GitHub Pages 或 EdgeOne Pages 时可直接运行。由于文章列表和详情页使用 `fetch()` 读取站内 JSON / Markdown，本地双击打开时可能受浏览器安全策略影响；本地预览建议使用任意静态文件服务器。

## 7. 后续可迭代方向

- 将 Markdown 自动抽取为 JSON，避免手动维护人物和文章卡片。
- 为每位受访者增加独立详情页。
- 增加「五年后回访」时间提醒与状态标识。
- 增加按主题检索的人生样本库。
- 将职业共享项目的贡献者数据接入真实动态致谢墙。
